# Framework provenance

The interactive demonstrator extends, rather than replaces, the public Version 1.0 pedagogical framework created by Mohit Tiwari.

- Original repository state before interactive implementation: [`622ca998f19ccd68ca398e36b04e0ff3c0308984`](https://github.com/profmohit-edu/context-driven-engineering-learning-framework/tree/622ca998f19ccd68ca398e36b04e0ff3c0308984)
- Original framework stages retained: context trigger activation; stakeholder identification and mapping; constraint structuring; trade-off evaluation; reflective decision justification.
- Original `impact.html` retained unchanged.
- Version 1.0 release/citation and CC BY 4.0 declaration remain part of the repository record.

Version 2.0 operationalizes those stages through deterministic, inspectable rules. It does not use generative AI and does not claim empirical learning-effect validation.
